Custom, fan-made skins for **Tribes 2**. The buttons above download all player
skins in a single `.vl2` file.

Choose **SD** for standard resolution or **HD** for hi-res textures (**QoL patch
required**). Both versions include the same skins, with the SD release downscaling
any HD skins (a small minority of the collection).

**Install:** Put **one** of the downloaded `.vl2` files in your Tribes 2
`GameData/base/` folder.

The buttons always download the latest release.
[Older versions and release notes](https://github.com/exogen/t2-skins/releases)
are also available. To browse or download individual skins, visit the
[skin gallery](https://skins.tribes2.online/gallery/).

For update notifications, choose **Watch → Custom → Releases** on this repo.

These skins are also used by:

- [t2-model-skinner](https://github.com/exogen/t2-model-skinner) — [Open the app](https://skins.tribes2.online/)
- [MapGenius](https://github.com/exogen/t2-mapper) — [Open the app](https://play.tribes2.online/)
